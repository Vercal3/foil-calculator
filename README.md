# Foil Calculator

[Foil Calculator](https://www.foilcalculator.com/) is a free online tool for multiplying binomials with the FOIL method — First, Outer, Inner, Last.

## How FOIL works

To expand (a + b)(c + d), multiply First (a times c), Outer (a times d), Inner (b times c) and Last (b times d), then combine like terms.

## Worked example

(x + 4)(x - 6): First gives x squared. Outer gives -6x. Inner gives 4x. Last gives -24. The simplified result is x squared - 2x - 24.

## Common mistakes

- Forgetting the Inner product entirely.
- Dropping a negative sign on the Outer or Last product.
- Adding the middle terms instead of combining them carefully.
- Stopping before simplifying, so the answer is not in standard form.

Check any answer by substituting a simple value for x into both the original product and the simplified expression.
